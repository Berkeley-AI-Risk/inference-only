# SimpleStories HWIC full model RTL regression

Completed November 4, 2026 UTC.

The integrated SimpleStories-V2-5M spatial candidate passed all seven original
numerical cases: **53 expected token outputs and 2,605,355 selected tensor and
logit comparisons**. All seven cases used the same compiled RTL image and the
unchanged W10/A16/KV16 BFP-v5 numerical reference. The 28 deliberately faulty
circuit runs also failed at their intended first tensor comparisons.

The [result record](evidence/integrated-model-2026-11-04/results.json) contains the case results, selected log lines,
full-log hashes, image and review identities, and measured process resources.
The [October 27 source checkpoint](simplestories-2026-10-27/README.md) remains the
published standalone reproduction baseline. This update archives the newer
spatial candidate's regression results. The spatial candidate's RTL and build
inputs are not included in the published source checkpoint. The published ROM
baseline and this private spatial candidate passed separate runs of the same
corpus; their identical token and comparison counts do not establish source
identity.

## Execution accounting

Generation, build and accepted replay comprise 45 native stages, using
291,359.337556 measured CPU seconds. Six interrupted
partial runs are retained separately and used
105,489.344424 additional CPU seconds. Three
were restarted early with larger runtime budgets. Three were stopped by an
overlarge build-stage disk reserve; the simulation-only reserve was corrected
after checking the replay write footprint. Two CPU admission declines created
no native model process. None of these interruptions counts as a numerical pass.

Per-stage wall times overlap because jobs ran in parallel. Parent and outer
controller CPU totals are excluded from the native sums. New paid-service
charges were $0; project-wide provider token allocation, billing, local energy
and total research cost remain unpriced.

## ASIC implementation work

This bounded RTL regression validates the fixed numerical function on its
recorded corpus. The next implementation comparison needs routed timing,
representative-activity power and a credible physical ROM/SRAM plan. Full-chip
clock/reset design, physical verification, PVT analysis and manufacturing-test
design remain qualification work. SimpleStories remains the first ASIC target,
with reusable AWIC/HWIC components and spatial parallelism as priorities.

The research draws on [HNLPU, *Hardwired-Neurons Language Processing Units as
General-Purpose Cognitive Substrates*, arXiv:2508.16151v2](https://arxiv.org/abs/2508.16151v2).
The current implementation uses fixed ROM and arithmetic adapted from the AWIC
token core, including the tested spatial datapaths. HNLPU's custom physical weight-routing method remains
an implementation to compare; this checkpoint establishes no comparative
silicon speed or area advantage.
