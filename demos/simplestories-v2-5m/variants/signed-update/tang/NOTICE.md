# Incorporated source and test material

The native project incorporates the enclosing SimpleStories-V2-5M demo's hardware under the repository's Apache 2.0 [license](../../../../../LICENSE). Its copied source and the S-AWIC changes are identified by the integration snapshot and build-input hashes. The active page-bank and SHA sources are the original native blocks. The complete project's separate fixed-weight image and numerical reference remain dependencies of the enclosing demo.

Proprietary GOWIN DDR/PLL sources are not included. The build verifies separately acquired inputs using the enclosing demo's [dependency manifest](../../../VENDOR-DEPENDENCIES.json). No proprietary source, license credential or installer is bundled by this integration.

The public RFC 8554 test data and demo signer policy have the provenance and limitations described in the parent [NOTICE.md](../NOTICE.md) and [SIGNED-UPDATE.md](../SIGNED-UPDATE.md). Demonstration keys and deterministic synthetic test signatures do not provide production authorization security.
